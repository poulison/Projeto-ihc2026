Os SVGs são a fonte: textos, caixas e setas podem ser editados em qualquer editor vetorial. As imagens PNG foram exportadas a partir deles (`rsvg-convert arquivo.svg -o arquivo.png`).

**Notação.** Caixa preenchida: objetivo final. Caixa clara com borda contínua: objetivo instrumental direto. Caixa com borda tracejada: objetivo instrumental indireto. Seta contínua: apoia o objetivo final na mesma interação. Seta tracejada: prepara condições para que o objetivo seja alcançado depois.
